# الحبيب ماب

مشروع مستقل للموقع والخادم وAndroid وiOS. المعرف sa.madarij.app محفوظ للتوافق مع التطبيق الحالي. أزيلت إعدادات وأصول وأوامر المنتج الآخر، مع الاحتفاظ بالمكونات المشتركة اللازمة.

## الاستخدام

- npm ci لتثبيت الاعتماديات داخل هذا المجلد.
- npm run dev للواجهة.
- جهز قاعدة MySQL منفصلة ثم انسخ .env.example إلى .env.local وأكمل بيانات الاتصال قبل تشغيل npm run api.
- npm run verify للتحقق الكامل وnpm run build لبناء الموقع.
- npm run build:mobile لبناء واجهة التطبيق.
- npm run native:android وnpm run native:ios لمزامنة المصادر. تجميع iOS يحتاج macOS وXcode.

لم تُنقل بيانات الطلاب أو قواعد الإنتاج أو الأسرار أو جلسات التشغيل أو مفاتيح التوقيع أو إعدادات Firebase أو بيانات النشر أو سجل Git أو الإصدارات الجاهزة. أضف إعدادات التشغيل والتوقيع الخاصة بالحبيب ماب عند الحاجة. المجلد الأصلي محفوظ؛ لا روابط أو اعتماد على ملفاته، ولا نشر على المواقع.
