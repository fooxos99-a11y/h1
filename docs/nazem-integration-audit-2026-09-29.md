# مراجعة ربط ناظم — 2026-09-29

النطاق: الكود المحلي للحبيب ماب، ومسار اعتماد التسميع ومزامنته. لم تُستخدم حسابات ناظم الحقيقية أو قاعدة الإنتاج، ولم يحدث نشر.

## النتيجة

القرار النهائي: إعادة زر الربط وتقييمه المستقل، مع اعتماد متبادل محلي قبل إرسال الحفظ. يسجل المعلم الحفظ والربط بأي ترتيب؛ الربط ينتظر الحفظ في ناظم، والحفظ ينتظر تسجيل نتيجة جميع مقاطع الربط محليًا. بعدها يحمل طلب الحفظ عدد الربط، وتؤكد عملية الربط وصول العدد دون كتابة ثانية.

- نتيجة «لم يتم الربط» تسجل صفرًا وتكمل الاعتماد المحلي، ولا تنتظر نجاحًا لم يحدث.
- لا يُرسل الحفظ عند وجود مقطع ربط بلا محاولة رسمية أو بلا عدد محفوظ.
- حفظ آخر مقطع ربط يوقظ الحفظ المعلّق لنفس المعلم والطالب والخطة والتاريخ. يعاد فحص الاستيقاظ عند تسجيل حالة الانتظار أيضًا لمعالجة تزامن العمليتين.
- لا يضاف شرط جديد إلى طلب سبق بدء إرساله؛ يستمر التحقق من نتيجته تحت حماية سجل الإرسال.
- لا تغير الواجهة تقييم ربط الطالب غير المرتبط بناظم ولا سياسة مكافآته.
- المتأخر والإتقان والمراجعة مستثناة من شرط انتظار الربط؛ ليس لها عقد الحفظ اليومي نفسه. لا ينتظر الحفظ ربطًا غير موجود ضمن مهام يومه.

## الحماية القائمة التي روجعت

| المجال | التنفيذ والدليل المحلي |
| --- | --- |
| حفظ النتيجة قبل الشبكة | `offlineRecitationService` و`offlineRecitationStore`؛ اختبار المتصفح يشغّل الحفظ عبرهما ويطابق بيانات الطلب |
| منع الطلب المتكرر | مفتاح idempotency في `queue` وسجل started/accepted/rejected في `recitationSubmission` |
| انقطاع بعد الإرسال وإعادة تشغيل العامل | اختبارات `nazemDeliveryIntegrity` تثبت عدم تكرار الكتابة قبل إثبات النتيجة |
| هوية الطالب والخطة واليوم والمقدار | تثبيت المصدر قبل الإرسال والتحقق من المعرّفات والمحاولات؛ لا نقل للتقييم إلى يوم آخر |
| انتهاء جلسة القراءة | إعادة مصادقة محدودة مرة واحدة عند 401/419 في `adapter`؛ كتابة غير مثبتة لا تعاد عميانيًا |
| ترتيب العمل | حجز مهام العامل، وترتيب المتأخرات، والتحقق من الحضور والأيام السابقة |
| تأكيد النتيجة | إعادة قراءة سجل ناظم ومطابقة المقدار والمقاييس؛ نجاح HTTP وحده لا يكفي |
| النقاط والمطابقة | تسوية مستقلة بمعاملة وقفل الطالب، واختبارات منع إعادة المنح والتراجع عند فشل السجل |
| التشغيل اليومي | جدولة تحديث المتابعات، واستعادة العمليات، والمطابقة الليلية مع تعويض المواعيد الفائتة |

## التحقق وحدوده

اختبارات وحدة وانحدار مع ناظم محاكى، وبوابة `npm run verify`، ومتصفحا Chromium وWebKit بمقاسات 360 و768 و1440. يغطي اختبار الواجهة زر الربط وتقييم مقاطعه واستعادة البيانات المخزنة بعد فشل التحميل. اختبارات المحول تغطي الترتيبين والعدد صفر أو موجب في كتابة واحدة وإعادة المحاولة دون كتابة ثانية. اختبار MySQL معزول على loopback يغطي اكتمال مجموعة الربط، وعزل الاستيقاظ، والتراجع عن المعاملة.

هذه أدلة محلية، وليست شهادة تشغيل على خادم الإنتاج أو جهاز iPhone فعلي. قبل التعميم التشغيلي يلزم نشر مصرح به ثم تجربة محدودة ومراقبة سجل المزامنة والمطابقة باستخدام حساب معتمد. لا يوجد ضمان ضد تغيّر واجهات ناظم الخارجية؛ API رسمي يبقى التحسين الخارجي الأهم عند توفره.
